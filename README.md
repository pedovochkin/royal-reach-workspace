# Royal Reach Workspace

Публичный интерактивный frontend-прототип CRM и обучения продажам. Вымышленные люди, клиенты и переписки; сервера и реальных интеграций нет.

- [Пространство руководителя](https://pedovochkin.github.io/royal-reach-workspace/?v=workspace-3&role=manager#overview)
- [Пространство сотрудника](https://pedovochkin.github.io/royal-reach-workspace/?v=workspace-3&role=employee#overview)

## Два сценария работы

**Руководитель** начинает с общей операционной доски. Видит пять сотрудников, этапы и суммы сделок, учебные оценки и четыре блока обучения. Нажатие на этап или фильтр сотрудника открывает соответствующие диалоги в списке под доской. Справа находятся вопросы клиентов и очередь учебных выводов. Доступны профили команды, проверка выводов, публикация знаний, описание интеграций, экспорт и сброс демо.

**Сотрудник** начинает с личной очереди и выбранного вопроса клиента. Видит только свои карточки, переписки и задачи. Может отвечать в учебном чате, менять этап своих сделок, добавлять задачи, проходить тренажёр и читать утверждённые знания. Учебный вывод отправляет на проверку руководителю; самостоятельно публиковать его в общей базе не может.

Выбор роли сохраняется в браузере. Параметр `role=manager` или `role=employee` позволяет отправить ссылку на нужный вариант. Переключатель демонстрирует модель доступа, **не является авторизацией**. Все данные доступны в публичном JavaScript и localStorage. Для рабочей системы нужны аутентификация, серверная проверка прав и политики Supabase RLS.

## Что попробовать

1. В роли сотрудника: «Тренажёр» → «Мои диалоги» → выбрать диалог → «Отправить на проверку».
2. Переключиться на руководителя: вывод появится в «Точках внимания». Проверить, отредактировать и утвердить — материал появится в «Знаниях».
3. На пульте нажать на этап у конкретного сотрудника: список покажет соответствующие сделки. Профиль сотрудника открывает его клиентов, прогресс и сводку навыков.
4. В роли сотрудника открыть тренажёр: правило → тест → свободный ответ. Для успешной практики нужны задача клиента, уточняющий вопрос и следующий шаг. Блоки открываются последовательно, баллы начисляются один раз.
5. В ежедневной практике можно выбрать цель 15, 20 или 30 минут. В демо доступен подготовленный сценарий.
6. «Диалоги» сохраняют учебные сообщения, «Мои клиенты» — этапы и новые вымышленные контакты. Сообщения никому не отправляются.
7. Поиск показывает клиентов в границах выбранной роли и утверждённые материалы с источниками.

## Структура

- `src/main.jsx` — оболочка, выбор роли, навигация, диалоги и модальные сценарии.
- `src/workspaces.jsx` — общая доска, личный рабочий поток, тренажёр, библиотека и профили.
- `src/ui.jsx` — базовые элементы, пиктограммы и доступные модальные окна.
- `src/access.mjs` — фильтрация данных и ограничения обновлений для демороли сотрудника.
- `src/model.mjs` — учебные данные, сохранение, локальная оценка ответа и поиск знаний.
- `src/workspace.css` — актуальная тема и адаптивные рабочие пространства.
- `src/style.css` — базовые стили общих форм, чата и диалогов.

Интерфейс использует системные шрифты и собственные SVG-пиктограммы. Основные сценарии работают без внешних сетевых запросов. Сборка добавляет хеш к ссылкам CSS и JavaScript для обновления кеша.

При переработке изучены [обновление интерфейса Linear 2026](https://linear.app/now/behind-the-latest-design-refresh), [отчёты и детализация Attio](https://attio.com/help/reference/managing-your-data/dashboard-and-reports/reports) и [фокусные очереди Superhuman](https://new.superhuman.com/split-inbox-63665). Реализация и композиция экранов собственные.

## Запуск и проверки

```sh
npm install
npm run build
npm run dev
npm test
```

Локальный сервер: http://127.0.0.1:4173. Тесты `node:test` проверяют восстановление состояния, требования к свободному ответу, поиск только по утверждённым материалам и ограничения деморолей. В браузере проверены фильтр доски, отправка и утверждение вывода между ролями, поиск сотрудника, закрытый маршрут, тренажёр и ширина 390 px.

## Границы прототипа

Данные сохраняются только в localStorage этого браузера, без синхронизации устройств и вкладок. Старые демоданные и прогресс сохраняются при обновлении. Подсказки и разборы подготовлены заранее, оценка ответа выполняется локально по учебным признакам. Настоящие GPT API, Telegram, MAX, Supabase, уведомления и серверные права не подключены. Статические оценки других сотрудников — вымышленные примеры, не кадровые рекомендации.
